# Supabase Backend Setup Guide & SQL Scripts

Follow this guide to connect your Rajowalia Storefront frontend to your Supabase backend, set up product image capabilities, and enable order email notifications to `rajowaliaryk@gmail.com`.

---

## 1. Setup Your Database Tables
Go to your **Supabase Dashboard** -> **SQL Editor** -> click **New Query**, paste the script below, and click **Run**:

```sql
-- 1. Create Products Table
CREATE TABLE IF NOT EXISTS public.products (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL,
    emoji text,
    image text, -- Stores Base64 product image string
    brand text NOT NULL,
    name text NOT NULL,
    price numeric NOT NULL,
    old_price numeric,
    badge text,
    stars numeric DEFAULT 5,
    in_stock boolean DEFAULT true NOT NULL,
    discount_percentage numeric DEFAULT 0,
    category text NOT NULL
);

-- Enable RLS & RLS policies
ALTER TABLE public.products ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public read access" ON public.products FOR SELECT USING (true);
CREATE POLICY "Allow admin write access" ON public.products FOR ALL USING (true);

-- 2. Create Customers Table
CREATE TABLE IF NOT EXISTS public.customers (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL,
    name text NOT NULL,
    email text UNIQUE,
    phone text UNIQUE,
    location text,
    total_orders numeric DEFAULT 0
);

ALTER TABLE public.customers ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public access for auth" ON public.customers FOR ALL USING (true);

-- 3. Create Orders Table
CREATE TABLE IF NOT EXISTS public.orders (
    id text PRIMARY KEY, -- Holds order number e.g. #LX-1234
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL,
    customer_id bigint REFERENCES public.customers(id) ON DELETE CASCADE,
    customer text NOT NULL,
    location text,
    sector text,
    item text NOT NULL,
    price numeric NOT NULL,
    method text DEFAULT 'COD',
    status_icon text DEFAULT '📦',
    status_text text DEFAULT 'Order Placed'
);

ALTER TABLE public.orders ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public access for orders" ON public.orders FOR ALL USING (true);

-- 4. Create Cart Items Table
CREATE TABLE IF NOT EXISTS public.cart_items (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL,
    customer_id bigint REFERENCES public.customers(id) ON DELETE CASCADE,
    product_id bigint REFERENCES public.products(id) ON DELETE CASCADE,
    quantity numeric DEFAULT 1 NOT NULL,
    UNIQUE (customer_id, product_id)
);

ALTER TABLE public.cart_items ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow user access for cart" ON public.cart_items FOR ALL USING (true);

-- 5. Create Wishlist Items Table
CREATE TABLE IF NOT EXISTS public.wishlist_items (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL,
    customer_id bigint REFERENCES public.customers(id) ON DELETE CASCADE,
    product_id bigint REFERENCES public.products(id) ON DELETE CASCADE,
    UNIQUE (customer_id, product_id)
);

ALTER TABLE public.wishlist_items ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow user access for wishlist" ON public.wishlist_items FOR ALL USING (true);

-- 6. Create Subscribers Table
CREATE TABLE IF NOT EXISTS public.subscribers (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamp with time zone DEFAULT timezone('utc'::text, now()) NOT NULL,
    email text UNIQUE NOT NULL
);

ALTER TABLE public.subscribers ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public insert" ON public.subscribers FOR INSERT WITH CHECK (true);
CREATE POLICY "Allow admin read" ON public.subscribers FOR SELECT USING (true);

-- 7. Create Settings Table
CREATE TABLE IF NOT EXISTS public.settings (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    email text NOT NULL
);

ALTER TABLE public.settings ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow read" ON public.settings FOR SELECT USING (true);
CREATE POLICY "Allow update" ON public.settings FOR ALL USING (true);

-- 8. Create Shipping Table
CREATE TABLE IF NOT EXISTS public.shipping (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name text NOT NULL,
    price numeric NOT NULL
);

ALTER TABLE public.shipping ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow read" ON public.shipping FOR SELECT USING (true);
CREATE POLICY "Allow write" ON public.shipping FOR ALL USING (true);

-- 9. Create Categories Table
CREATE TABLE IF NOT EXISTS public.categories (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name text NOT NULL,
    image text
);

ALTER TABLE public.categories ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow read" ON public.categories FOR SELECT USING (true);
CREATE POLICY "Allow write" ON public.categories FOR ALL USING (true);

-- 10. Create Discounts Table
CREATE TABLE IF NOT EXISTS public.discounts (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    code text UNIQUE NOT NULL,
    discount_percent numeric NOT NULL,
    active boolean DEFAULT true NOT NULL
);

ALTER TABLE public.discounts ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow read" ON public.discounts FOR SELECT USING (true);
CREATE POLICY "Allow write" ON public.discounts FOR ALL USING (true);
```

## 3. Uploading Product Images
Your Admin Panel is already coded with base64 conversion handlers. 
- Go to the **Admin Dashboard** in your storefront.
- When creating or editing a product, click the **Choose File** / upload selector button.
- Choose any image from your computer. 
- The image will automatically be converted to a compressed string and saved to the `image` column in your Supabase `products` database table.
- All product grids and cart items will dynamically read and render these images.

## 4. Setting Up Email Notifications (Free Web3Forms)
To start receiving real-time order alerts to `rajowaliaryk@gmail.com`:
1. Go to [Web3Forms](https://web3forms.com/) (Free, no account needed).
2. Enter your email address `rajowaliaryk@gmail.com` and click **Create Access Key**.
3. You will instantly receive a key (e.g. `12345678-abcd-1234-abcd-1234567890ab`) in your inbox.
4. Add it to your `.env.local` file:
   ```ini
   VITE_WEB3FORMS_KEY=your-access-key-here
   ```
5. Restart your development server (`npm run dev`). 
6. Place a test order! You will instantly receive a formatted order summary email to `rajowaliaryk@gmail.com` detailing the customer's name, phone, city, ordered items, and price.
